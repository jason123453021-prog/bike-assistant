# 智慧單車助手雙主題設計系統

## 目標

本規範以騎乘中短暫注視、日光反射與單手操作為優先，讓淺色與深色模式都能以相同的資訊層級表達導航、運動數據、設定與警示。這不是單純反轉黑白，而是為每個表面層級、文字角色與狀態建立對應色彩。

## 色彩與表面

| 令牌 | 淺色模式 | 深色模式 | 使用位置 |
|---|---|---|---|
| `background` | 低飽和霧白 | 深墨綠黑 | 全頁底色 |
| `surface` | 純白 | 深森林綠 | 一般卡片、列與彈窗 |
| `surfaceElevated` | 純白 | 較亮深綠 | 選取列、浮動面板與重點區塊 |
| `surfaceInset` | 淺綠灰 | 近黑綠 | 搜尋列、內嵌資訊、圖表底板 |
| `foreground` | 深森林黑 | 近白綠 | 標題、關鍵數值與主要操作文字 |
| `muted` | 深灰綠 | 淺灰綠 | 輔助說明、單位、時間與圖例 |
| `accent` | 深青綠 | 明亮薄荷綠 | 已選取、主要動作、進度與正向數值 |

## 字體與資訊層級

| 層級 | 字級／字重 | 用途 |
|---|---|---|
| 頁面標題 | 26–30 / 700–800 | 導航、紀錄、設定與詳情主標題 |
| 區塊標題 | 16–18 / 700 | 卡片名稱與主題分組 |
| 列標題／重要數值 | 15–17 / 600–800 | 設定名稱、活動名稱、即時數值 |
| 內文與說明 | 13–15 / 400–600 | 引導、狀態、日期與理由 |
| 極簡輔助資訊 | 最小 11–12 / 600 | 單位、圖例、短時間戳；不以淡色單獨承載關鍵資訊 |

## 元件規範

1. 卡片使用 `surface`，背景與卡片以 1 px `border` 分隔；不要以透明度過低的邊框傳達區塊。
2. 主要按鈕與設定列最小高度 48dp；相鄰可點擊元件至少保留 8dp 間距。
3. 深色導航浮層使用 `overlay` 或至少 0.92 不透明背景；所有文字、圖示與次要數值維持可見對比。
4. 綠、黃、紅狀態必須同時搭配文字、圖示或邊框，避免只依顏色表示狀態。
5. 多欄運動數據只保留一眼必要資訊；詳細指標進入展開區或詳情頁，避免主畫面擁擠。

## 驗收基準

- 小文字至少使用符合高對比需求的 `muted`，不可使用低於 0.70 alpha 的白字承載重要資訊。
- 深色與淺色模式均由同一個 runtime palette 驅動容器、文字與卡片，避免主題不同步。
- 手勢、按鈕與確認操作符合最小 44–48dp 可點擊目標。
