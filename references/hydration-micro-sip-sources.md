# 智慧補水小量分次調整：來源紀錄

本機智慧補水的調整採用以下可操作原則：補水量應配合個人汗率、體重、強度、時長與環境，而非固定單次大量灌水；運動中以小量、規律的補充取代單次大容量建議。系統將把每次提醒限制在可耐受的範圍，並以 10–15 分鐘的預估補水節奏拆分總需求。

| 來源 | 與本次邏輯相關的重點 |
|---|---|
| [Judge et al., 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8336541/) | 文中整理 NATA 建議：運動中補水以接近汗液／尿液流失為目標；一般可透過每 10–20 分鐘攝取 200–300 mL 達成，且需求應依體重、汗率與環境個別化。 |
| [Merritt, Ozga & Hinkley, 2025](https://www.gssiweb.org/en/sports-science-exchange/article/hydration-and-nutrition-considerations-forendurance-cycling-exercise-in-the-heat) | 單車汗率可隨強度、熱濕、風況、訓練／熱適應等顯著變動；建議補水避免超量，並透過訓練建立個人腸胃耐受度。 |
| [ACSM Position Stand, 2007](https://pubmed.ncbi.nlm.nih.gov/17277604/) | 運動中補水目的在避免過度脫水與過量飲水造成的電解質失衡；本機模型使用保守上限與分次提示。 |
| [NATA Position Statement, 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5634236/) | 建議將補水依個人汗率與環境個別化，避免運動期間體重增加與過量飲水；因此本機倒數以個人化汗率模型為核心，並將短週期提示維持保守。 |
| [Vitale & Getzin, 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6628334/) | 耐力活動超過 60 分鐘才需主動補充碳水；1–2.5 小時常用 30–60 g/h，且建議以每 10–15 分鐘的分次攝取提升耐受度。App 以此作為能量提醒的下限時長與分次倒數基準，而非固定量化處方。 |

本文件僅作演算法設計依據，不能取代個人醫療、腎臟／心血管疾病或運動醫學建議。
