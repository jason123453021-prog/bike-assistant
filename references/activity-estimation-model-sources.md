# 本機活動估算模型：研究限制與來源

本功能僅用於離線活動回顧中的**趨勢估算**；介面必須維持「本機估算」標示，不得取代或偽稱外接心率帶、踏頻器或功率計的量測。

心率趨勢採用心率儲備（HRR）概念，依使用者最大心率、靜息心率與本機騎乘強度估算。HRR 的一般形式為 `(HRmax − RHR) × 強度 + RHR`；相關研究亦指出，未經個人化測試的心率方法在不同強度下應謹慎使用，因此本 App 以低／中／高信心分級呈現，並不做醫療或訓練處方。

踏頻研究指出，個人較適踏頻會隨工作率、騎士與長期實測資料而異；研究中的個人最佳化需要功率、心率、踏頻等長期量測。本 App 因不要求外接裝置，僅根據速度、坡度、虛擬功率、FTP 與使用者 RPE 建立保守的趨勢模型，且只用多次本機 RPE 調整強度範圍（上限 ±8%）。
