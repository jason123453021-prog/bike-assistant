# 重新釘選導航路徑分析

目前導航頁透過單一 `sharedRoute` 將 GPX 與 OSRM 釘選導航路徑寫入同一來源；釘選與 POI 導航皆直接呼叫 `setSharedRoute`，因此會覆寫既有路線。Leaflet 地圖元件目前接收單一 `gpxPolyline`，方向箭頭也隨該單一路徑渲染。

本次調整需在建立新釘選導航前辨識既有 GPX 或釘選圖層，顯示清除確認。確認清除時必須清空所有舊導航圖層與箭頭；取消清除時需保留現有路徑並以不同顏色疊加新 OSRM 路徑。

Leaflet 目前的 `setGpxPolyline` 直接建立方向箭頭標記但未保存其引用，因此後續覆寫或清空折線時可能留下小箭頭。重構需改為以具名圖層集合保存折線、起訖標記與箭頭，並在每次圖層集合更新時先統一移除所有舊引用。
