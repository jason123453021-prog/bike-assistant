## 已修正與強化項目

| 面向 | 已完成的優化 | 預期效果 |
|---|---|---|
| 靜態品質 | 移除未使用的 GPS 漂移常數；修正 Hook 依賴；移除地圖與補給高頻開發日誌。 | 降低 lint 雜訊與定位回呼期間的非必要輸出。 |
| 型別安全 | 自訂補給追蹤器由 `any` 改為明確資料結構，包含提醒與重複計時器欄位。 | 讓計時器初始化與釋放更容易被編譯期檢查。 |
| 定位與羅盤 | GPS 與電子羅盤非同步訂閱改為各自持有實例；若畫面卸載或設定變更先發生，晚到訂閱會立即移除。 | 避免切換騎乘狀態後留下位置或航向監聽。 |
| 寫入節流 | 前景崩潰恢復快照維持 3 秒合併；背景軌跡維持 5 秒批次並限制至 10,000 點。 | 避免每一筆定位都重寫本機資料，並限制長時間騎乘的記憶體與儲存成長。 |
| 儲存防呆 | 活動記錄寫入成功前不再清除崩潰恢復快照；若本機儲存失敗，保留可恢復資料並顯示中文提示。 | 降低儲存空間不足時遺失本次騎乘的風險。 |
| 版面／權限 | Safe Area 容器、Android 底部導航列間距與權限失敗中文提示均已列入守門測試。 | 改善瀏海、圓角及系統列裝置上的可用性與錯誤可理解性。 |

## 測試與維護守門

新增健康度守門測試，檢查：活動保存後才清理恢復資料、非同步 GPS／羅盤訂閱可釋放、補給追蹤器不再使用寬鬆型別，以及高頻補給除錯日誌不會重新引入。

> 本次完成的是 Android JavaScript／Hermes 匯出驗證。完整 APK／AAB 的 Gradle 任務仍應於正式 EAS 或本機 Android SDK 環境執行，以覆蓋原生編譯器與簽章流程。
