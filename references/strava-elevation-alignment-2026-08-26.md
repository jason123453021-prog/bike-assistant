# Strava 海拔與爬升對齊基準（2026-08-26）

本文件僅記錄 Strava 官方公開說明，不將未公開的私有演算法稱為可複製的「底層代碼」。

| 公開原則                                                                          | 本 App 對齊決策                                                                                        |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 具氣壓高度計的原始檔以原始氣壓資料為主，並做較少的平滑與離群值捨棄。              | 若日後可取得可信氣壓高度，應保留來源與優先權；目前手機 GPS 高度仍以保守平滑與離群限制處理。            |
| 無氣壓高度計或手機 App 記錄時，Strava 將 GPS 點與海拔資料庫交叉比對並做較多平滑。 | 本機無離線 DEM／Strava basemap，不假稱可完全重現；確保即時、活動儲存、恢復及匯出共用同一個濾波資料鏈。 |
| 公開 FAQ 指出：非強氣壓資料的爬升必須持續超過 10 m 才累加；具氣壓資料為 2 m。     | 對純 GPS 即時資料採更高的可設定一致門檻，並用相同過濾器重建最終紀錄，避免短時 GPS 垂直雜訊被重複累加。 |
| Strava Android 即時海拔源自 GPS 位置，因此較容易出現與修正後活動不同的值。        | UI 明確使用「GPS 估算」語意；不承諾和 Strava 修正後 DEM 值完全相同。                                   |
