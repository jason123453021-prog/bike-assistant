# Velodash 公開功能與 Local-First 篩選

研究日期：2026-08-12

| 官方來源 | 公開描述的能力 | Local-First 判定 |
| --- | --- | --- |
| [Velodash 官網](https://www.velodash.co/) | 團騎、分享路線、騎友即時位置、附近活動與活動管理 | 團騎、即時位置、活動探索與組織後台需帳號及網路，排除；路線資訊呈現可作為純本機 UI 參考。 |
| [Velodash FAQ](https://www.velodash.co/faqs-eng) | 手繪路線、從收藏／歷史／GPX 建立路線、經停點、抵達提醒、GPX 匯出 | GPX 匯入已具備；從歷史建立路線與本機經停點可完全離線實作。 |
| [Velodash App Store](https://apps.apple.com/us/app/velodash-cycle-together/id1329905651) | 路線分析、騎乘紀錄、可自訂儀表、自動暫停、深色模式、BLE 感測器及團騎功能 | 本 App 已有路線／騎乘分析、面板、自動暫停、深色模式及 BLE；團騎／活動／討論／共享紀錄需帳號與網路，排除。 |

| Velodash 概念 | 本 App 現況 | 本輪處理 |
| --- | --- | --- |
| 從歷史騎乘建立路線 | 已保存騎乘軌跡，尚無直接重用入口 | **已新增**：由騎乘記錄卡片將本機軌跡轉為導航路線並立即再次導航。 |
| 團騎、即時位置、活動探索、報名、公告 | 已依需求移除所有雲端與社群功能 | **永久排除**：違反不登入、無雲端與 Local-First 原則。 |

> 所有新增資料僅在裝置內既有 AsyncStorage 騎乘紀錄與記憶體導航 Context 流動，不上傳位置、不建立帳號，也不使用額外原生模組。
