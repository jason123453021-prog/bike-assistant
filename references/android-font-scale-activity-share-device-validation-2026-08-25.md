# Android 多語系字體大小、活動標題與分享圖卡實機驗收

本流程用於實機確認長字串在 Android 系統字體大小 **130%** 與
**200%** 下仍可閱讀，且不因德文、俄文或阿拉伯文而被省略截斷。

| 範圍     | 驗收操作                                                   | 預期結果                                                                                  |
| -------- | ---------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 系統字體 | Android「設定 → 顯示 → 字體大小」依序設為 130%、200%       | App 重新開啟後字級跟隨系統；內容可捲動且無重疊。                                          |
| 設定表單 | 切換 Deutsch、Русский、العربية，開啟設定數值與補給品 Modal | 標籤、錯誤與按鈕先縮放；仍過長時換行，不顯示省略號。                                      |
| 活動標題 | 建立或編輯含長德文複合詞、長俄文、阿拉伯文活動名稱         | 地圖頂部與活動摘要均完整呈現；名稱編輯欄可使用兩行。                                      |
| 分享圖卡 | 從活動詳情開啟分享圖卡並建立圖片                           | SVG 預覽與實際 PNG 的標題、統計標籤、單位與底部說明完整可讀；長標題可分行，統計格不重疊。 |
| RTL      | 使用 العربية 重複上述步驟                                  | 文字右對齊，操作列方向正確，沒有被左側圖示或關閉按鈕遮蓋。                                |

若發現截斷，請回報 Android 版本、裝置解析度、系統字體比例、App
語言、畫面名稱與截圖。GitHub Emulator 會在 130% 與 200% 下保存英文、德文、俄文及
阿拉伯文設定頁截圖，作為可重現的基準 artifact。
