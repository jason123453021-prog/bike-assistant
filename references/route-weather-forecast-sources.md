# 路線預覽天氣與風向預報

路線預覽會以起點座標查詢未來數個小時的溫度、相對濕度、風速、風向與降雨機率。這些資料只在匯入時可連線取得；若無網路或沒有快取，App 仍使用保守的本機預設值，並明確標示離線回退。

| 資料 | 用途 |
|---|---|
| 溫度、濕度、天氣代碼 | 空氣密度、熱負荷、水分消耗 |
| 風速、風向 | 依每段路線航向計算逆風分量，進入功率—速度與完成時間模型 |
| 降雨機率 | 顯示出發前風險，並對水分熱負荷採取保守調整 |

> 天氣預報是規劃資料，不是即時路況；完成時間與補給量仍為離線估計值，會隨實際風況、交通、休息與路面狀況而變動。

## 參考資料

1. [Open-Meteo Weather Forecast API Documentation](https://open-meteo.com/en/docs)：`hourly` 可提供按小時的 `temperature_2m`、`relative_humidity_2m`、`wind_speed_10m`、`wind_direction_10m` 等欄位；回傳的每個時間陣列以 ISO 8601 時間戳對應。
