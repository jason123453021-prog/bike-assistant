# Strava 活動頁 Local-First 功能對照

研究日期：2026-08-13。此文件僅作為本機離線騎乘活動頁設計依據；不導入帳號、雲端社群、公開排行榜或付費服務。

| Strava 活動頁能力 | 可否以本機實作 | 單車助手對應方向 |
| --- | --- | --- |
| 固定活動總覽、展開更多數據與地圖 | 可以 | 活動主視覺、核心成績、完整數據區與本機路線圖。 |
| 速度、海拔、功率、心率、踏頻等分析曲線 | 可以（有原始資料時） | 互動式曲線、距離／時間切換、游標讀值與選取區間摘要。 |
| 每公里分段、裝置圈數與活動選取範圍 | 可以 | 每公里分段、可選本機區間分析、GPS 時間序列有圈數時顯示圈數。 |
| 個人最佳、路段成就、目標 | 可以（限定本機歷史） | 本機 PR、最佳努力、每週／每月目標、連續騎乘與個人洞察。 |
| 功率曲線、功率區間、心率區間、25W 分布 | 可以（取決於收集資料） | FTP 驅動的功率區、功率曲線、心率／踏頻曲線與可用資料的空狀態。 |
| 描述、私人備註、媒體、活動類型、裝備、主觀強度 | 可以 | 活動名稱、描述、私人本機備註、照片／影片、騎乘類型、單車／裝備與 RPE。 |
| 裁切、分割、修正 GPS／距離／海拔 | 部分可行 | 先實作只讀範圍分析與本機資料品質提示；資料編修必須保留原始備份。 |
| 公開路段榜、KOM/QOM/CR、好友、按讚、留言、追蹤 | 不納入 | 需要帳號、公共路段庫或社群服務，違反 Local-First／無登入限制。 |
| 天氣 | 可以（僅保存騎乘時本機快照） | 顯示已保存的溫度、濕度、風況，不於歷史頁另行連網。 |

## 官方來源

1. [Ride Activity Pages](https://support.strava.com/en-us/articles/15401886-ride-activity-pages)：活動總覽、路段、分析、心率、功率曲線、區間、圈數與編輯選項。
2. [Viewing Activities](https://support.strava.com/en-us/articles/15401943-viewing-activities)：活動地圖、分析、分段結果與可用感測資料。
3. [Your Activity's Top Results](https://support.strava.com/en-us/articles/15402021-your-activity-s-top-results)：最佳表現、路段成就與目標的摘要方式。
4. [Activity Split Tool](https://support.strava.com/en-us/articles/15401842-activity-split-tool)：使用曲線與範圍選取進行活動拆分的資料互動模式。
