# 待機定位與設定圖示分析

導航頁目前在元件掛載時立即請求前景定位權限並建立 `watchPositionAsync`，即使騎乘狀態尚未開始，仍持續更新位置、速度與地圖。羅盤僅依賴車頭朝前模式，尚未依賴騎乘是否開始。

`handleStart` 已會設定 `mapRideActive`、建立背景追蹤與天氣計時器，`handleStop` 也會停止這些資源。因此前景 GPS 與羅盤訂閱應同樣以 `mapRideActive` 為唯一生命週期開關，讓暫停中的既有騎乘繼續記錄，但尚未開始的待機畫面不啟用定位服務。

設定頁未直接使用問號圖示；Android 的 `IconSymbol` 對未映射的符號名稱會回退為 `help-outline`，因此需補齊設定頁實際使用的符號映射，避免出現不明問號。
