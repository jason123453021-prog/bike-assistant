# 單車助手 1.0.103 Google Play 發布說明草案

> **狀態：待使用者確認後才能輸入並送交 Google Play。** 本文件只描述已實作修正，不代表已上傳、送審或發布。

## 面向使用者的更新內容

| 類別 | 已完成修正 |
| --- | --- |
| 地圖 | 移除會顯示 `API KEY REQUIRED` 的 Carto 圖磚來源，改用具 OpenStreetMap 署名的道路圖磚。 |
| POI | 補水點與拍照點在初次載入、手動平移、縮放、GPS 置中與 GPX／釘選路線改變後，都會依可視範圍更新；公開資料來源暫時失敗時會嘗試後備來源，並保留裝置端 30 分鐘快取與 30 秒失敗重試節流。 |
| 觸控鎖 | 解鎖進度僅由有效觸控指標啟動；指標取消、離開前景或無效事件會清除進度，避免無觸控仍停在 100% 的畫面。 |
| 用詞 | 統一繁中產品名稱為「單車助手」，將「結束騎程」「騎程次數」等修正為「結束騎乘」「騎乘次數」，並校正相關介面詞彙。 |

## 建議的「最新更新」文字

```text
• 修正地圖上出現 API key 錯誤文字的問題，改善道路名稱顯示。
• 改善補水點與拍照點在騎乘、GPX 路線與釘選路線中的即時更新與服務容錯。
• 修正未觸控時可能殘留的長按解鎖進度。
• 修正騎乘結束、騎乘統計與產品名稱的繁中用詞。
```

## 發布前邊界

本版不新增帳號、雲端同步、好友位置共享、OSRM 真實道路導航、自動偏離重算、轉彎語音或任何 NitroModules／C++ 高風險原生模組。地圖與 POI 仍需使用者主動連網取得公開資料；若無網路，僅能保留已在裝置端快取的 POI，不能宣稱完整離線地圖。

## POI 公開資料來源備註

OpenStreetMap 的 Overpass API 是唯讀查詢服務；其公開執行個體可能因負載進行限流或短暫不可用，因此本版保留單一可視範圍查詢、30 分鐘裝置端快取、30 秒失敗重試節流與依序後備端點，避免高頻 GPS 置中造成重複請求。[1] [2]
