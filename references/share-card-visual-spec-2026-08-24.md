# 本機騎乘分享圖卡版面規格

更新日期：2026-08-24

本規格以 1080 × 1920 直式社群影像為目標，採用深色地圖主視覺與高對比統計網格。資料優先順序參考 Strava 公開的騎乘分享欄位：**距離、移動時間、爬升**；不複製其商標、私有版面或未公開演算法。

| 區塊 | 內容 | 視覺與資料規則 |
|---|---|---|
| 識別列 | 單車助手、運動類型、活動日期 | 小型全大寫英文品牌與繁體中文運動類型；只標示本機產生。 |
| 路線主視覺 | 完整 GPS 軌跡、起點、終點、方向進度點 | 上半部主畫面，等比例 fit bounds；綠色起點、暖橘終點、亮綠軌跡，不拉伸經緯度。 |
| 活動標題 | 騎乘名稱 | 單行大標；過長時由 SVG 安全截斷，避免跨出畫面。 |
| 核心統計 | 距離、移動時間、爬升 | 第一層三欄，固定欄寬、數字基線與單位區。移動時間僅取可信 GPS 資料鏈。 |
| 次要統計 | 平均速度、平均功率、卡路里 | 第二層三欄；平均功率資料不足時顯示「--／資料不足」，不顯示虛構 0 W。 |
| 資料語意 | GPS 記錄、本機離線產生 | 頁尾小字，不將總經過時間混入平均速度，也不宣稱與第三方完全一致。 |

> 無 GPS 路線時，圖卡須顯示明確空狀態與統計，不生成假地圖。沒有照片不構成錯誤；本卡預設以路線為主視覺。
