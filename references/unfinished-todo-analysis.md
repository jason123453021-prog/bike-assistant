# 未完成待辦盤點與優先分析

**分析日期：** 2026-08-13  
**現行產品原則：** Android 優先、Local-First、Expo SDK 54、React Native、純 TypeScript／官方 Expo 模組、零 NitroModules、無帳號／社群／雲端同步。

## 結論摘要

`todo.md` 仍保留約 140 筆未勾選項目，但其中大量內容屬於早期版本的重複紀錄、已完成功能的舊子任務，或與目前產品原則衝突的帳號、社群、雲端與原生橋接方案。它們不應直接作為開發順序。真正值得保留的工作只有三類：**實機可靠性驗證、歷史資料的可讀性增強，以及不新增高風險依賴的本機分析功能**。

> 騎乘 App 的下一個里程碑不應是再增加大型模組，而是以實機長時間測試確認背景定位、崩潰恢復、補給通知與觸控鎖定在 Android 上可用；這是目前最高的使用者安全與資料價值風險。

## 不應承諾的驗收事項

Android 或 iOS 不能保證「永不被系統終止」。App 可透過 Expo 官方背景定位、前景服務設定、即時持久化與重啟恢復降低風險，但仍必須以不同品牌 Android 裝置的長時間實測作為驗收依據。補給建議同樣是依個人、騎乘與環境資料的估算，不取代醫療或運動營養專業判斷。
