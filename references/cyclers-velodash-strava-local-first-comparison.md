# Cyclers、Velodash 與 Strava：Local-First 功能比對

研究日期：2026-08-12

## Cyclers 官方資料

來源：[Cyclers FAQ](https://cyclers.app/faq/)

| 功能或說明 | 本機實作判定 |
| --- | --- |
| 已規劃路線可在離線時導航，同時追蹤騎乘；離線時無法規劃新路線或重新規劃 | 可借鑑：本 App 已採 GPX 與既有路線的 Local-First 導航；不應在無網路時宣稱可取得新 OSRM 路線。 |
| 因背景省電可能造成軌跡直線、鋸齒或中斷，建議將 App 加入電池最佳化白名單 | 可借鑑：強化騎乘開始前的背景保護檢查與可讀取的設定引導；不需帳號。 |
| 里程記錄可依年度／期間篩選 | 可借鑑：以本機歷史紀錄加入週、月、年及自訂期間統計；不需帳號。 |
| 公里／英里單位設定 | 可借鑑：加入全域單位偏好並在現有指標／GPX 中一致轉換；不需帳號。 |
| 自動重新規劃與語音導航列為 Cyclers Plus 能力 | 可借鑑的語音提示已存在；依專案需求排除偏離後自動重新規劃。 |
| 地圖回報、使用者報告、遊戲點數、雲端同步、個人檔案、外部帳號登入 | 排除：依賴帳號、伺服器資料或社群驗證。 |

> Cyclers 官方 FAQ 明確指出：離線時可使用已規劃路線與騎乘追蹤，但新規劃與重新規劃需要資料連線；本 App 將維持此誠實的 Local-First 邊界。

## Velodash 官方資料

來源：[Velodash 官方網站](https://www.velodash.co/)

| 功能或說明 | 本機實作判定 |
| --- | --- |
| 路線資訊、行程與騎乘路線分享 | 可借鑑：本 App 已有 GPX 匯入、歷史軌跡重用與本機 GPX 備份，可進一步加入本機路線經停點。 |
| 路線檢查點與地理圍欄 | 可借鑑：能在已載入 GPX 上以本機座標建立接近提醒，不需登入或雲端。 |
| 團騎、即時騎士位置、活動探索、報名、公告、組織者後台與社群互動 | 排除：官方網站明示為群組／組織連線功能，依賴帳號與即時伺服器資料。 |

## Strava 官方資料

來源：[訂閱功能](https://support.strava.com/en-us/articles/15402044-strava-subscription-features)、[活動記錄](https://support.strava.com/en-us/articles/15402137-recording-an-activity)、[訓練日誌](https://support.strava.com/en-us/articles/15402077-training-log)

| 功能或說明 | 本機實作判定 |
| --- | --- |
| 訓練日誌、週／月／年統計、距離／時間／爬升檢視與目標 | 可借鑑：可只分析裝置內歷史騎乘，完全離線實作。 |
| 個人最佳、常用路線的歷史表現比較 | 可借鑑：本 App 已有本機 PR 與路線統計，可擴充成本機訓練日誌。 |
| Live Segments、完整排行榜、個人熱圖、建議路線、Beacon、安全聯絡人與雲端匹配騎乘 | 排除：需要 Strava 帳號、他人／群眾資料、網路或安全聯絡人驗證。 |
| 心率與功率區間、訓練負荷、疲勞／恢復等訂閱分析 | 可借鑑：用既有的本機功率、心率與騎乘紀錄計算；不需要付費或登入。 |

## 優先實作決策

優先加入 **本機訓練日誌月曆與週／月累積統計**：它直接整合 Cyclers 的期間統計與 Strava 訂閱的 Training Log 概念，只讀取現有 AsyncStorage 騎乘紀錄，不需要網路、帳號、外部地圖或高風險原生相依。
